# 测试与交付说明

验证日期：2026 年 10 月 12 日。

## 环境与结果

Ubuntu 24.04 / WSL2、GCC 13.3、CMake 3.28、Qt 6.4，WSLg 使用 xcb 窗口后端。

Debug 构建成功，源代码没有编译警告。CTest 的三个测试程序全部通过：`core_tests`、`console_tests`、`gui_tests`。此外在 WSLg 的实际图形环境中运行了整套 GUI 操作测试，结果通过，并保存了六张窗口截图。

校园主题改进后，还验证了 640×620、1080×720、1920×1080、2560×1600 和实际最大化窗口下的登录页与账户页，并保存对应截图检查布局。验证照片资源内嵌、面板和字体同步放大、控件不被父页面裁切、缩回普通窗口恢复原尺寸、双行时钟完整可见且不与操作面板重叠、装饰文字清理，以及弹窗、表格和曲线同步放大。默认账户数据不会被测试使用或覆盖。

## 手工可复查的结果

第一张卡初始余额 1000.00 元；存款 200.50 元后为 1200.50 元；取款 100 元后为 1100.50 元。记录包含两笔，余额曲线包含初始点和两笔交易后的点。

取款 50 元失败，取款 2000 元失败，这两次不会产生记录或改变余额。密码改为 012345 后，旧密码失效，新密码可登录。第二张卡仍为 2500.00 元且无记录。

测试使用临时数据文件，默认账户保持初始余额和密码。实际 `atm_gui` 从项目以外的当前目录启动后保持运行，标准错误输出为空；控制台直接启动、输入结束退出正常。

## 交付范围

本阶段完成源代码、构建与 VS Code 配置、运行说明、代码讲解及测试。正式课程报告与演示视频未制作，留待后续。界面截图仅用于程序布局检查。

这是一份课程模拟程序，不提供注册、管理员、转账、加密或多进程同时修改账户文件的功能。程序只做正常业务输入和文件错误检查。
